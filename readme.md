# TeamFinder

TeamFinder — веб-приложение на Django для поиска участников в pet-проекты.  
Платформа помогает разработчикам находить единомышленников для совместной работы над проектами, формировать команды и обмениваться опытом.

## 📖 О проекте

TeamFinder решает проблему поиска команды для pet-проектов. Часто разработчикам сложно найти мотивированных людей с нужными навыками для реализации своих идей. Наше приложение предоставляет удобный инструмент для:

- **Создания проектов** и описания задач
- **Поиска участников** среди зарегистрированных пользователей
- **Формирования команд** через систему заявок
- **Сохранения интересных проектов** в избранное
- **Просмотра профилей** участников с информацией о навыках и опыте

### Основные возможности

#### Для пользователей:
- Регистрация, вход и выход из аккаунта
- Редактирование профиля и смена пароля
- Просмотр списка пользователей и публичных профилей
- Создание, редактирование и завершение проектов
- Просмотр списка проектов и страницы конкретного проекта
- Добавление проектов в избранное
- Участие в чужих проектах

#### Фильтрация пользователей по критериям:
- Авторы избранных проектов
- Авторы проектов, в которых пользователь участвует
- Пользователи, которым нравятся проекты пользователя
- Участники проектов пользователя

#### Администрирование:
- Управление пользователями и проектами через Django Admin

## 🚀 Развертывание проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/Timmy0309/team-finder-ad.git
cd team-finder-ad
```

### 2. Настройка виртуального окружения

**Создание виртуального окружения:**
```bash
python -m venv venv
```

**Активация окружения:**

| ОС | Команда |
|---|---|
| Windows (PowerShell) | `venv\Scripts\Activate.ps1` |
| Windows (cmd) | `venv\Scripts\activate` |
| Linux/Mac | `source venv/bin/activate` |

**Установка зависимостей:**
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Скопируйте пример конфигурации:
```bash
cp .env_example .env
```

Откройте файл `.env` и заполните переменные:

| Переменная | Описание | Пример |
|---|---|---|
| `DJANGO_SECRET_KEY` | Секретный ключ Django. Можно сгенерировать через `python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"` | `django-insecure-&amp;8x@...` |
| `DJANGO_DEBUG` | Режим отладки (`True` - разработка, `False` - продакшн) | `True` |
| `POSTGRES_DB` | Имя базы данных | `team_finder` |
| `POSTGRES_USER` | Имя пользователя БД | `team_finder` |
| `POSTGRES_PASSWORD` | Пароль пользователя БД | `secure_password` |
| `POSTGRES_HOST` | Хост БД (для Docker - `localhost` или имя сервиса) | `localhost` |
| `POSTGRES_PORT` | Порт БД | `5432` или `5436` |
| `ALLOWED_HOSTS` | Список разрешенных хостов через запятую | `127.0.0.1,localhost` |

### 4. Запуск PostgreSQL

Для работы приложения используется PostgreSQL, запускаемый в Docker:

```bash
docker-compose up -d
```

**Проверка работы контейнера:**
```bash
docker ps
```

**Остановка контейнера:**
```bash
docker-compose down
```

> **Примечание:** Если порт 5432 уже занят, измените порт в `docker-compose.yml` (например, `5436:5432`) и соответствующую переменную в `.env`.

### 5. Применение миграций и запуск

**Создание миграций:**
```bash
python manage.py makemigrations
```

**Применение миграций:**
```bash
python manage.py migrate
```

**Создание суперпользователя (для доступа в админку):**
```bash
python manage.py createsuperuser
```

**Запуск сервера разработки:**
```bash
python manage.py runserver
```

После запуска проект будет доступен по адресу: [http://localhost:8000](http://localhost:8000)

- Сайт: http://localhost:8000
- Админ-панель: http://localhost:8000/admin
